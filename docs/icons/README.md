# Icons

The SVG files here are from the official AWS Architecture Icons package
(<https://aws.amazon.com/architecture/icons/>, July 2026 release), renamed to the short keys used in
`ARCH_ICONS` in `scripts/build_questions.py`. Files ending in `-dark.svg` are the dark-theme variants of
the general icons. `group-*.svg` are the AWS group icons used on diagram boxes.

The AI/ML service icons (`bedrock`, `agentcore`, `sagemaker`, `comprehend`, `quick`, …), the SageMaker AI
resource icons (`model`, `train`, `notebook`, `canvas`), and the extra general icons (`document`, `chat`,
`code`, `tool`, `app`, `search`, …) come from the same package's July 2026 release (`Icon-package_07312026`).
